## The line

> I didn't miss the deadline, I just gave it a head start so it could enjoy being early for once.

## How it works

`main.py` (Python standard library only, no network, deterministic) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
